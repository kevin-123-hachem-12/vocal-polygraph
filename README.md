# Vocal Polygraph (Veritas VP-9)

A novelty voice lie detector that runs in the browser. Press the red button, say something about yourself, press again, and the machine stamps **LIE** or **TRUTH**.

- Measures pitch, tremor, pauses and hesitation from your voice, and turns your speech into text.
- Optional: add an Anthropic API key in Settings (gear icon) to let Claude judge your wording and voice. The key is stored only in your browser.
- Vibrates on Android phones; shakes and buzzes everywhere.

For entertainment only. No machine can truly detect a lie.
